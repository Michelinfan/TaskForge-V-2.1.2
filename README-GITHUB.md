# TaskForge 2.1.2

Corrección de creación de proyectos y edición de tareas, manteniendo los sonidos por prioridad y las notificaciones en segundo plano.

## Crear el instalador de Windows
En GitHub, abre **Actions** y ejecuta **Build TaskForge 2.1.2 for Windows**. Descarga el artefacto `TaskForge-2.1.2-Windows`.

Consulta `README-2.1.2.txt` para los detalles y el alcance de esta entrega.
