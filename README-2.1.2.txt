TaskForge 2.1.2 — corrección de Proyectos y edición de tareas

CAMBIOS
- El botón + de PROYECTOS abre ahora un formulario integrado en la aplicación, sin usar prompt().
- Se pueden crear proyectos con validación de nombres duplicados y entrar directamente al proyecto creado.
- Se puede editar una tarea existente desde el icono del lápiz: título, prioridad, fecha, hora y proyecto.
- Se conservan los sonidos WAV por prioridad y la infraestructura de notificaciones en segundo plano de la 2.1.1.
- Versión del instalador: 2.1.2.

INSTALACIÓN / BUILD
1. Sube el contenido del ZIP al repositorio GitHub sustituyendo los archivos existentes (no borres la carpeta .github).
2. Abre Actions.
3. Ejecuta “Build TaskForge 2.1.2 for Windows”.
4. Descarga el artefacto TaskForge-2.1.2-Windows y dentro encontrarás el instalador .exe.

IMPORTANTE SOBRE MÓVIL Y NUBE
Esta entrega todavía no implementa la app Android/iPhone ni el backend de sincronización en Internet. Eso requiere una fase adicional: servicio de cuentas, sincronización segura y app móvil. Las funciones locales de escritorio se preparan primero para reducir riesgos y mantener las notificaciones estables.
