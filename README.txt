TASKFORGE V1 — INSTALADOR WINDOWS

Este proyecto incluye la configuración de electron-builder para generar un instalador
.exe real de Windows (NSIS), con acceso directo en el escritorio y en el menú Inicio.

Para construirlo:
1. Instala Node.js.
2. Ejecuta CREAR-INSTALADOR.bat.
3. El instalador aparecerá en release/TaskForge-Setup-1.0.0.exe.

Una vez creado el .exe, TaskForge se podrá instalar como una aplicación normal de Windows.
